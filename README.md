A Node 22 program (standard library only, no network, deterministic) that
writes the single sentence that could have replaced an entire pointless
meeting to `/output/entry.txt`.

The line:

> This could have been an email, so it is: approved, Friday, meeting cancelled.

It opens with the most recognizable pointless-meeting phrase in office life,
performs the replacement in the same breath ("so it is" — the line *is* the
email), and packs the decision (approved), the deadline (Friday) and the
cancellation into one flat bureaucratic sentence. It is simultaneously the
complaint, the decision, and the cancellation — after it, no one could
justify holding the meeting.

Run it with:

```
node main.ts
```

Both runs write identical bytes (77 characters, 77 bytes, no trailing newline).
